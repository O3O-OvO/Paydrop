# Paydrop
You work and you get paid per sec.

薪动是一款 Windows 桌面记薪挂件，按日薪展示收入、标准秒薪、下班倒计时和工作时长。保留极简透明、夜晚、定制小八三种主题，以及背景和整体不透明度设置。

## 1.2.0 更新

1.2.0 包含以下功能：

- **作息估算 / 实际打卡**：估算按计划工作日计算，不伪造历史；实际模式支持开始、临时无薪休息、继续和结束。普通工作到计划下班时自动结束，加班需主动记录。
- **灵活作息**：多段有薪或无薪休息、跨午夜班次、每周工作日、特殊日期覆盖、独立加班倍率（1–5 倍）。
- **工作记录**：本周、本月、全部班次汇总，实际收入、工作 / 加班 / 无薪时长与 CSV 导出。记录沿用首次打卡时的薪资快照，不随以后修改设置而改变。
- **桌面控制**：单实例、托盘恢复、关闭到托盘、记住位置、80–150% 缩放、置顶开关、2 / 4 位金额精度。
- **直接调整大小**：挂件底部百分比按钮打开大小滑块，可恢复 100%；右下角手柄支持拖动等比缩放。Web 预览和 Windows 窗口都响应同一个缩放设置，大小随设置保存；小八、金额和计时一起缩放。
- **小八桌宠**：独立透明窗口，使用 AI 生图制作的待机眨眼、走路、开心跳跃、吃吐司、坐下休息、挥手、伸懒腰、开心摇摆、抱金币九组逐帧动画，共 54 帧。支持摸摸、投喂、手动休息、拖动、收起与托盘唤回；新动作通过网页互动按钮或桌宠的“更多动作”菜单触发。可跟随作息，调整大小（70–140%）与不透明度（30–100%）。默认不开启，不改变计薪或打卡状态。
- **挂件内陪伴**：默认在计薪挂件底部显示动态小八，金额和倒计时保留独立空间。摸摸、投喂、挥手、伸懒腰、摇摆、抱金币和手动休息可直接触发；工作恢复时挥手，进入休息时伸懒腰，下班时庆祝，每赚满一元伴随金币掉落抱金币，手动互动不会被金币打断。暂停展示也会暂停小八动画。顶部爪印切换陪伴区，窗口随之在 380 × 400 与 380 × 304 间切换；设置可单独控制挂件内小八与独立桌宠。
- **数据可靠性**：双窗口同步、字段级冲突检测、原子写入、上一份数据备份、配置导入导出和可查看的更新日志。配置导出不包含工作记录。

### 计薪规则

标准秒薪 = 日薪 ÷（计划班次秒数 − 计划无薪休息秒数）。实际记录只累计已打卡时段，计划无薪休息和临时休息不计入工作；计划有薪休息继续计薪。主动加班开启计薪时按标准秒薪 × 倍率累计，否则统计为无薪时长。计划上班前主动打卡的工作不计薪。

跨午夜的普通班次归属开始日期；普通班次在计划结束时间自动关闭，即使应用当时没有运行，也会在下次打开时按计划结束时间收尾。主动加班可跨日，但需要手动结束，不自动推断离岗或系统闲置。暂停展示仅冻结显示，不等于休息或结束打卡。

Electron 数据保存在系统 `userData` 下的 `data.json`，备份为 `data.json.backup`；原有 `settings.json` 只读取迁移，不删除。Web 使用同源浏览器存储，两者是独立数据。特殊日期由用户维护，不联网推断节假日。

## 安装与更新

从本仓库 Releases 下载最新版 `Paydrop-Setup-*-x64.exe`，安装后应用会自动检查并下载新版本。更新准备好时，可点击挂件上的重启图标完成安装；退出应用也会安装已下载的更新。旧便携版需要手动安装一次安装版才能加入自动更新。

Windows 安装包若未使用代码签名证书，可能出现 SmartScreen 提示。发布步骤见 [UPDATING.md](UPDATING.md)。

## 本地开发

```sh
npm ci
npm run dev
```

应用入口为 `index.html`、`widget.html` 和桌宠互动预览 `pet.html`。Web 预览只在页面里移动；挂件顶部爪印控制挂件内小八，陪伴区的弹出按钮、工作台“独立桌宠”开关或托盘可开启独立透明桌宠，透明空白区域支持鼠标穿透。桌宠偏好与现有设置一起保存，位置单独保存在 `pet-window.json`。

`npm test` 执行计薪、记录、设置冲突、持久化、桌宠行为与更新流程测试；`npm run build` 验证生产构建；`npm run desktop` 打开本地 Electron 开发版。

桌宠透明动画素材在 `public/pet-art/v2/`，每组为 6 帧横向 PNG 条带，每帧 256 × 288。`manifest.json` 保留原生生图工具的生成记录、完整提示词、帧时长和轮廓范围。`scripts/prepare-pet-sprites.py` 用于整理已生成的源图，只进行透明边缘清理、颜色统一、裁切与基线对齐，不用立绘变形伪造动作。关闭动态效果或开启系统减少动态时，桌宠停留在对应静态帧。

本地打包默认使用 `O3O-OvO/Paydrop` 更新源，可用 `GITHUB_REPOSITORY` 或 `PAYDROP_GITHUB_REPOSITORY` 显式覆盖；占位仓库 `example/*` 会被拒绝。更新代码后，需要升版本并完成发布，安装版才会收到新功能。
