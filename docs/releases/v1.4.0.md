# 薪动 Paydrop 1.4.0：中国日历与桌面体验

## 中国日历

- 新增月历、农历日期、法定节假日与补班标记，支持查看和调整单日工作安排。
- 内置中国大陆 2025–2026 年官方放假调休数据，需要在计薪设置中主动启用；默认沿用原有每周作息。
- 手动日期设置优先于官方日历，官方安排优先于每周作息。未覆盖年份明确提示并回退到每周规则。
- 跨午夜班次以开始日期判定，已打卡班次保留原计薪快照；不会自动调整加班工资倍率。
- 日历采用双栏布局，优化三种主题、窄屏、日期选中态和信息对比度。

## 日常操作

- 设置按计薪与作息、外观与桌宠、提醒与桌面、数据与更新分组，切换分组保留未保存内容。
- 挂件新增紧凑、标准、陪伴三种布局，桌面窗口高度同步适配。
- 明确区分工作休息、数字显示冻结和桌宠休息；冻结显示不停止真实工作状态更新。
- 长时间加班提醒可直接补填真实结束时间，保留之前的工作分段、修改原因与修订记录。
- 优化窄屏工作记录、长记录分段展开、备份入口与离开编辑时的草稿保护。

## 升级须知

- 支持自动更新的 Windows 安装版可检查更新，下载完成后重启安装；便携版请手动下载安装包。
- 保留既有设置与工作记录，不会自动结束遗留班次。建议升级前导出完整备份。
- 备份时间仅表示发起导出，不保证文件已保存到磁盘。
- 未配置代码签名时，Windows 仍可能显示安全提示。
- 本轮已进行隔离数据的 Web/Electron 验证，不代表真实用户安装升级流程已完整验收。

## 验证记录

- 127 项单元测试及生产构建通过。
- 日历覆盖三种主题、六种视口尺寸，检查布局、键盘操作与文字对比度。
- 隔离 Electron 场景验证设置持久化、窗口布局、补填结束时间及挂件同步。
