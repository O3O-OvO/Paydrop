# 薪动 Paydrop 1.3.0：记录可纠错

## 计薪状态更清楚

- 区分当前计薪速度与标准秒薪：无薪加班、无薪休息时当前速度为零，不再让标准秒薪看起来像收入仍在增长。
- 加班时显示已加班时长，结束后才显示班次已结束；临时休息不累计工作、加班时长或收入。
- 提示当前班次沿用首次打卡时的薪资和作息参数；外观与提醒设置立即生效。
- 加入可关闭、可调整阈值、可延后提醒的长时加班提示，不自动推断用户离岗。

## 工作记录可核对与修正

- 点击班次日期查看实际工作、临时休息、加班时段、收入依据和冻结的薪资快照。
- 支持手动补录漏打卡班次，修正忘记结束的真实时间；保存前可核对收入与工作时长变化。
- 保留原始时段、修改原因及全部修订历史，不再因达到 10 次修订而禁止继续纠错。
- 删除的已结束记录进入回收站，可恢复；冲突时拒绝覆盖另一窗口的新记录，编辑草稿保留。
- 未修改的打卡时间保留毫秒精度，不因编辑说明而舍入。

## 完整备份与恢复

- 完整备份包含设置、工作记录、分段、薪资快照、修订历史和回收站，与仅导出设置的配置备份分开。
- 恢复前校验并显示预览，采用完整替换，不做跨设备自动合并；进行中班次需要明确核对。
- 替换前独立保存当前数据，可在备份面板恢复到替换之前；日常保存不会覆盖这份快照。
- 修复连续选择备份或切换恢复前快照时，慢旧请求覆盖新预览的问题；旧读取报错也不会影响新选择。
- 写入或快照保存失败时保留原数据，不把失败操作标为成功。

## 升级与使用须知

- 支持自动更新的 Windows 安装版可检查更新，下载准备好后点击重启更新。便携版需手动运行 `Paydrop-Setup-1.3.0-x64.exe`。
- 保留既有设置和工作记录，不改写已打卡班次的计薪参数，不自动结束遗留加班。
- 将今天设为工作日不会覆盖仍在进行的旧班次；忘记结束时，请在对应班次的“修正打卡”中补填真实结束时间，再开始新班次。
- 使用新记录与回收站功能后建议保留完整备份，不建议降级到旧版本；旧版不支持这些数据扩展，可能丢弃回收站或无法读取新修订历史。
- 完整备份导入上限仍为 16 MB；Web 与安装版的数据相互独立。安全 Web 记录修改需要支持 Web Locks 的新版浏览器。
- 未承诺跨时区迁移、云同步或真实安装升级的完整验收；未配置代码签名的安装包仍可能出现 Windows 安全提示。
