# 薪动 Paydrop 1.4.1：更清晰的工作与休息体验

## 体验优化

- 新用户首次进入时确认日薪、工作时间、休息安排、工作日、日历规则和计薪模式，避免把示例配置当成实际收入。
- 工作台压缩顶部布局，让收入、下班倒计时和工作时长在桌面首屏可见。
- 明确标注历史未结束班次及日期，可直接进入核对；不会自动结束历史记录，正常跨夜班次也不会提前被标记。
- 休息时显示本次已休息时长，覆盖临时休息和计划休息；紧凑挂件同步显示休息计时。
- 进度条明确表示计划班次进度，而非收入进度；休息日与加班状态不再显示误导性进度。
- 外观设置新增实时挂件预览，支持主题、透明度、尺寸与布局预览，保存后才应用。
- 修复 Electron 本地页面下外观预览消息未生效的问题，预览不会改动真实薪资与工作记录。

## 升级须知

- 保留既有设置与工作记录，老用户无需重新完成首次配置。建议升级前导出完整备份。
- 支持自动更新的 Windows 安装版可检查更新，下载完成后重启安装；便携版请手动下载安装包。
- 未配置代码签名时，Windows 可能显示安全提示。

## 验证

- 139 项单元测试及生产构建通过。
- Web 验证覆盖首次配置、休息与恢复、记录导航、外观预览隔离，以及三套主题的五种视口尺寸。
- 隔离 Electron 验证覆盖预览、设置同步、重启持久化、历史记录核对、窗口尺寸与日历同步。
- 上述隔离验证不等同于真实用户安装升级的完整验收。
