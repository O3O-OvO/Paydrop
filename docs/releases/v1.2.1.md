# 薪动 Paydrop 1.2.1：安心陪伴

## 小八与挂件

- 重绘“歇一会”的六帧表情：柔和闭眼、小微笑，休息循环放慢到 6.1 秒。挂件和独立桌宠同步使用新素材，原身体原画和透明边缘保留。
- 小八主动休息时，不再被整元金币和作息变化自动叫醒；手动摸摸、投喂等互动仍然有效，互动结束后继续休息。
- 主动休息、待打卡、作息休息和下班显示不同陪伴文案；小八休息不会暂停计薪。
- 挂件底部打卡按钮增加明确文字，区分临时休息、继续工作、开始工作与开始加班。
- 暂停展示时明确显示“展示暂停”，不再让用户误以为停止了计薪。
- 暂停、隐藏或关闭动态时停止挂件陪伴的逐帧计算，保留状态同步和静态展示。

## 防误操作

- 移除挂件的一键结束按钮；普通班次仍在计划下班时自动结束。
- 提前下班和结束加班放在工作台，并要求二次确认；取消不会改变记录。
- 结束请求校验班次 ID，避免旧确认误结束另一窗口新开启的班次。

## 发布与兼容

- 采用单草稿发布流程，安装包、差分文件和更新清单齐全后才设为正式最新版。
- 保留现有薪资、作息、历史、主题和透明度设置；没有更改计薪公式。
- 已安装支持自动更新的安装版，可检查更新，下载完成后点击重启更新。便携版请手动运行 `Paydrop-Setup-1.2.1-x64.exe`。
- 此版本仍未配置 Windows 代码签名证书，可能出现 SmartScreen 提醒。
- 休息素材为既有原生生成原画的局部重绘，原始来源与编辑信息保留在 manifest 中，不宣称为新 AI 生图。

完整迭代方案见仓库 `docs/iterations/v1.2.1.md`。
