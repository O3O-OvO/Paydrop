# 薪动 Paydrop 1.2.0

## 新增

- 小八桌宠：九组 AI 生图逐帧动画，共 54 帧，支持摸摸、投喂、挥手、伸懒腰、开心摇摆和抱金币。
- 挂件内小八陪伴区：跟随工作、休息和下班状态，每赚满一元伴随金币掉落抱金币；也可打开独立透明桌宠。
- 挂件大小调节：底部百分比滑块、右下角等比拖动、恢复原始大小，支持 80% 到 150%，并保存设置。
- 实际打卡模式：开始工作、多次临时休息、继续工作、结束并保存记录。
- 灵活作息：多段有薪或无薪休息、跨午夜班次、每周工作日、特殊日期和加班倍率。
- 工作记录和汇总：按班次保存薪资快照，支持查看历史和导出 CSV。
- 桌面控制：托盘恢复、关闭到托盘、记住位置、置顶开关和金额精度设置。

## 改进

- 暂停展示同时暂停小八动画，不改变实际工作记录。
- 数字静态逐位更新，移除跳动和震颤。
- 改进多窗口设置同步、字段冲突检测、原子保存和数据备份。
- 改进自动更新错误提示，并提供更新诊断日志。

## 安装与更新

- 已安装支持自动更新的安装版，可在更新下载完成后点击挂件的重启更新按钮，或退出应用完成更新。
- 首次安装或便携版用户，请下载并运行 `Paydrop-Setup-1.2.0-x64.exe`。
- 薪资和作息设置会迁移到新数据文件；原有 `settings.json` 不删除。建议更新前导出配置备份。
- Web 预览和 Windows 安装版的数据分别保存在各自环境，不会相互覆盖。
- 本版未配置 Windows 代码签名证书，Windows 可能显示 SmartScreen 提醒。
