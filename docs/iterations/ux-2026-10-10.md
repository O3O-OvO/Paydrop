# 用户体验第一轮：状态、纠错和生效范围

状态：本地实现，等待 Web 验收；未打包或发布新 Release。

## 本轮范围

- 长时加班提醒明确班次日期，提供“补填结束时间”和“仍在工作”。
- “仍在工作”仅在本窗口延后一小时提醒，不修改工作记录。
- 补填表单只修改最后一段结束时间；保留原薪资快照、已有时段和修订历史。
- 保存之前必须核对收入与时长变化，拒绝未来时间、逆序时间和另一窗口已修改的记录。
- 挂件核对按钮直达对应班次，Web 与 Electron 均支持。已结束班次打开详情。
- Electron 工作台已经打开时复用窗口；离开已有表单前确认，取消后保留输入。
- 设置页把日薪、作息放在外观之前，区分本班参数、待保存参数和已保存的新参数。
- 优先展开存在差异的参数；无差异时可主动展开完整对照。
- 参数对照同时覆盖日薪、作息、计划休息、工作日、特殊日期和加班。
- 明确同日续班沿用原班次参数，作息估算保存后使用新参数。
- 工作休息按钮统一为“休息（不计薪）/ 继续工作”。
- 挂件的数字冻结入口移入“画面显示”菜单，冻结时仍显示真实工作状态和恢复入口。
- 休息或继续工作成功后退出数字冻结，避免显示旧金额；桌宠休息不修改打卡，改用月亮图标。
- 数字冻结与桌宠动作解耦，桌宠仍可以独立休息或互动。

## 第二轮：布局、记录与备份

状态：本地完成，等待 Web 验收，未打包或发布。

- 设置分为计薪与作息、外观与桌宠、提醒与桌面、数据与更新四组。
- 分组切换保留同一份草稿；支持左右方向键、Home 和 End，保存时定位首个无效字段所在分组。
- 首页缩短装饰背景区，保留小八素材，优先呈现工作操作与收入。
- 挂件“画面显示”菜单增加紧凑、标准、陪伴三种预设；设置中也可组合信息密度与小八开关。
- 紧凑模式只显示收入、倒计时和打卡操作；标准显示完整时长；陪伴增加桌宠互动。
- Web 与 Electron 共用高度计算；窗口缩放、拖动缩放与原有参数兼容，打包清单包含共用模块。
- 窄窗口工作记录显示摘要卡，保留日期、金额、各项时长、状态、详情及删除入口；宽屏保留表格。
- 超过四段的班次详情优先显示当前或最后一段，其余折叠；完整时段及原始修订历史不变。
- 完整备份入口前置，区别于配置导出；显示本设备最近发起导出的时间。
- 导出时间不是文件成功落盘证明；界面明确提示确认下载文件。恢复仍保留预览、确认、并发校验与恢复前快照。
- 设置中打开备份中心前确认离开，避免无提示丢失草稿。
