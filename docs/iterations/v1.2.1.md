# v1.2.1 迭代方案：安心陪伴

日期：2026-10-09（北京时间）。

## 设计方向

保留小八主题、极简透明、夜晚模式和现有布局。收入与工作状态仍是主信息，小八是安静的陪伴，不应打断操作或改变计薪。将桌宠互动、打卡休息、暂停展示三种含义分开。

## 本轮交付

| 优先级 | 问题 | 修改 | 验收依据 |
| --- | --- | --- | --- |
| P0 | 挂件结束按钮容易误触 | 挂件不再提供结束操作；工作台区分提前下班与结束加班，二次确认 | 取消确认不改变记录；正常班次仍按计划自动结束 |
| P0 | 确认期间班次可能在另一窗口变化 | 结束请求携带班次 ID，保存层校验仍是同一活跃班次 | 旧确认不能结束新班次或已经自动结束的班次 |
| P1 | 休息表情显得疲倦、半睁眼不够友好 | 六帧分别重绘为放松闭眼和小微笑；原身体、坐姿和透明轮廓保持不变 | 原图保留；透明通道和身体像素检查；挂件与独立桌宠都使用新素材 |
| P1 | 主动休息会被整元收入或作息事件叫醒 | 主动休息不接受自动抱金币、挥手或庆祝；用户手动互动仍可响应 | 手动互动结束后回到休息；计薪和工作记录不变 |
| P1 | 两个咖啡图标含义容易混淆 | 打卡按钮增加“临时休息／继续工作”等明确文字；桌宠休息按钮提示只影响小八 | 缩放 80%、100%、150% 无遮挡；键盘可操作 |
| P1 | 休息状态缺少上下文 | 主动休息、待打卡、作息休息和下班显示不同陪伴文案 | 静态模式与动态模式都能正确更新 |
| P2 | 暂停或关闭动态后挂件仍逐帧计算 | 暂停、隐藏、关闭动态或系统减少动态时停止挂件陪伴 RAF 循环；状态仍按秒同步 | 静态模式无持续动画帧；恢复动态可继续播放 |
| P2 | 发布可能暴露不完整更新附件 | 先构建，统一上传到单个草稿，附件齐全后再公开 | 正式 Release 只保留一个条目，包含 exe、blockmap、latest.yml |

## 美术来源

本轮没有可用的原生生图工具，不调用未经授权的付费 API，也不把程序绘图说成新 AI 生图。`rest-soft.png` 是对原生生成的 `rest.png` 做局部眼睛、眉毛、嘴巴重绘。原始生成信息与新增局部编辑信息分别保存在素材 manifest 中。

可复现命令：`python scripts/refine-rest-art.py`。原始 `rest.png` 不覆盖。休息循环从 3.5 秒延长到 6.1 秒；其余八套动作保留。

## 验收清单

- 全量单元测试、生产构建、连续三轮浏览器交互回归。
- 休息不停止计薪；临时休息会暂停该休息期间的实际计薪。
- 取消提前下班确认、确认结束、自动收尾、加班休息和结束、作息估算。
- 三主题、三种缩放、暂停恢复、减少动态、独立桌宠和原生透明窗口。
- 检查 canvas 非空、六帧变化、静态帧、素材加载和控制台错误。
- GitHub Actions 构建、发布附件完整性和公开更新清单。

本轮采用实际画面自检，未进行独立设计评审，不给虚假的设计评分。对比图与浏览器截图放在 `output/imagegen/rest-refinement/`、`output/playwright/`，不随应用安装。

## 发布前验收结果

- 63 项单元测试通过，生产构建通过。
- 结束确认与工作状态浏览器回归连续三轮通过。
- 表情、静态模式、金币不打断休息、三主题与三档缩放浏览器回归连续三轮通过。
- 原生透明挂件与独立桌宠回归连续三轮通过；恢复桌宠时先识别正确窗口再验收，不假定第一个窗口一定是挂件。
- 画面证据：`output/imagegen/rest-refinement/rest-comparison.png`、`rest-soft.gif`；`output/playwright/refinement-*-*.png`、`refinement-native-widget.png`、`refinement-native-pet.png`。
- 没有运行安装包覆盖用户当前安装；本机真实旧安装版升级、Windows 签名和更多高 DPI 设备仍属于后续验收。

## 下一轮建议

| 优先级 | 方向 | 原因 |
| --- | --- | --- |
| P1 | 工作记录纠错与安全撤销 | 误点和漏打卡应可修正，但需保留修改前记录，避免重复计薪 |
| P1 | 休息提醒与快捷键偏好 | 由用户选择提醒频率、时间段与免打扰，默认不强推提醒 |
| P2 | 更多真正逐帧的放松动作 | 原生生图可用后再做趴睡、喝水等新动作，不用立绘变形伪造新动作 |
| P2 | Windows 签名与真实旧版升级验收 | 减少首次安装阻力；使用独立测试账户验证安装、重启和数据迁移 |
| P2 | 多显示器与高 DPI 长时间稳定性 | 扩展实际设备覆盖，检查任务栏、休眠恢复和位置持久化 |

下一轮项目仅列为方案，本轮不虚称已完成，也不在安装包中放入未接通的控件。
