# 中国日历视觉精修

状态：本地 Web 实现，未打包发布；不改变日历数据与计薪规则。

## 设计判断

- 按用户要求使用本机 `design-taste-frontend` 的审阅、排版、节奏与预检方法。
- 该 skill 主要适用于展示页，不直接套用其营销布局；本项目继续使用原生 CSS 和已有 Lucide 图标，不引入新 UI 框架。
- 面向每天查看班次的桌面用户，采用紧凑月历与日期详情并排的工具布局。
- 参数：`DESIGN_VARIANCE = 4`，`MOTION_INTENSITY = 2`，`VISUAL_DENSITY = 6`。

## 原版观察

- 小八主题的大幅背景、规则和说明挤占月历上方空间。
- 所选日期详情位于月历下方，桌面核对日期后需要继续寻找操作。
- 今天只有文字下划线，与选中日期缺乏清晰的层级区别。
- 字体沿用 Segoe UI / Microsoft YaHei；青绿主色、深色文字与 4–8px 圆角继续保留。
- 导航名称、日期输入、改班按钮、日历开关及历史记录行为保持不变。

## 改动

- 日历页独立紧凑页头，保留小八头像，不改变其他页面的背景设计。
- 宽屏左月历右详情，窄屏自然上下排列；月份切换与回到今天集中在顶部。
- 工作日数与休息天数归入月份信息，不增加装饰性指标卡。
- 今日采用实心日期标记，选择态采用边框；放假区间使用浅玫红底，补班保持蓝色状态标记。
- 手动安排继续显示“自”，并提高文本对比度。
- 日期详情区显示生效依据、官方安排、作息和改班操作。
- 来源及计薪说明收进原生 details，内容完整保留，支持键盘。
- 只对悬停背景和展开箭头使用 120ms 过渡，减少动态偏好下禁用。

## 色彩与预检

- 原有主色 `#247c76`，正文 `#274f5c`，分隔线 `#cbdde1`。
- 放假语义色 `#a63d59`，补班语义色 `#276187`，各主题对应深色版本。
- 额外颜色仅用于状态区分，不作为多个品牌强调色。
- 业务回归沿用 `china-calendar-qa.cjs`；布局与对比度抽检使用 `calendar-taste-qa.cjs`。
- 覆盖三主题、320/390/768/1024/1280/1600 六种宽度、六行月份、日期徽标不重叠、来源说明键盘操作、抽样文字对比度。
- 截图位于 `output/playwright/calendar-taste/` 和 `output/playwright/china-calendar/`。
- 抽样对比度检查不等同完整无障碍审计。
