# v1.3.0 本地迭代：记录可纠错

日期：2026-10-10。该编号为建议发布版本，当前仅完成本地开发；`package.json` 仍为 1.2.1。未打包、提交、推送或发布，不替换用户安装版。

## 完成内容

- 班次详情：实际分段时间轴、收入 / 工作 / 加班 / 无薪时长、本班日薪与作息、加班倍率、计划休息。
- 打卡修正：填写真实的工作、临时无薪休息、加班开始和结束时间，支持多段休息、跨午夜、补填忘记结束的加班。
- 预览确认：先核对原记录与保存后收入 / 时长，再保存；输入改变会使旧预览失效。进行中的详情标为核对时刻快照。
- 修订留痕：保留原日期、完整时段、结束状态、原因与修订时间，始终沿用本班薪资快照。不开放薪资参数改写或重新开启已结束班次。
- 手动补卡：默认建议前一天的计划时段，选择日期时只调整未手动改过的默认时段；补录使用当前参数，带手动来源标识。
- 可恢复删除：已结束班次移入已删除记录，不计入汇总，可恢复；不提供隐式永久删除。
- 完整备份：独立的 `PaydropBackup` / `backupVersion: 1` JSON，含设置、记录、薪资快照、修订和已删除记录，区别于配置 JSON 与汇总 CSV。
- 安全恢复：文件验证、数量与日薪预览、明确替换确认、单独确认继续备份内的进行中班次。恢复后本地 revision 单调递增，不使用备份里的旧 revision。
- 恢复前快照：覆盖主数据前先独立保存当前数据，日常保存不覆盖此快照；界面可重新预览并恢复。每次成功恢复的下一次恢复都会重新保留当时当前数据，不提供无限代际备份。
- 多窗口保护：修改、删除、恢复记录核对完整记录快照；补卡与完整恢复核对 revision。拒绝冲突，保留编辑草稿。无 Web Locks 的浏览器拒绝这些写操作，桌面通过主进程串行处理。

## 校验与兼容

- 校验真实日期、有效时间戳、时段先后与重叠、结束边界、未知时段类型。
- 新编辑不能写入未来时间、零时长或开放时段；普通工作不能越过计划下班时间，工作日加班须在计划下班之后。
- 保存后为已结束班次，若需要继续工作，仍通过现有打卡操作开始。不会根据睡眠或系统闲置推断离岗。
- 不允许同日期新增另一条班次，也不允许与另一班次实际时段重叠。恢复同日期冲突时保留已删除记录，不自动合并。
- 不按修订次数锁死班次，完整保留每次修订与原始快照；界面单次最多添加 100 段，已有原始记录的验证上限仍为 10,000 段。未改变的时间保留原毫秒，不因编辑其他字段而舍入。
- 每类记录上限 10,000 条；完整备份导入上限 16 MB。数据满时明确报错，不静默淘汰历史。
- v3 旧数据缺少新字段时迁移为空已删除记录，不改变原薪资快照。新数据重读保留扩展字段。
- 旧应用不支持这些 v3 扩展，未验证降级兼容；旧版可能丢弃已删除记录。使用后应保留完整备份，不建议降级。
- 新数据模型依赖 `src/record-management.js`，已加入 Electron 打包文件清单；渲染层由 Vite 打包。
- Web 与安装版数据仍分离；本轮验证不读取或修改真实安装目录，也不修复用户那条异常长加班。
- 跨时区迁移未验收，班次日期与计划作息仍按设备本地时区解释。

## 视觉与交互

沿用已有三种主题、Lucide 图标与抽屉，不新增设计系统。列表中的日期进入详情；主动作是核对并保存，辅助动作安静放在工具栏。预览采用紧凑三列对照，历史和计薪参数为展开内容。

抽屉打开时背景工作台不可交互；保留 Escape、焦点循环和关闭后的焦点恢复，加入 textarea / summary 的键盘路径。编辑草稿由抽屉持有，不随记录汇总刷新丢失。

保留既有抽屉滑入 / 遮罩淡入，新预览轻淡入，不加数字震颤。减少动态模式继续关闭过渡。未进行独立设计评审或屏幕阅读器合规验收，已自检目标截图。
